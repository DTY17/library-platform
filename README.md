# ⚙️ Platform Services

The **Platform Repository** contains the core infrastructure services of the Library Management System: **API Gateway, Eureka Server, and Config Server**.

These services provide **API routing, service discovery, and centralized configuration** for the microservices architecture.

The platform services are deployed on the cloud and managed using **PM2** for process monitoring and automatic restarts.
